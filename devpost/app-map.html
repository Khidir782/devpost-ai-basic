Threads Insight Pipeline — App Map

Reference architecture, data flow, and key code locations for the completed proof of concept.

Next.js 15 • TypeScript • Gemini 2.5 Flash • Zod Validation

System Overview

Threads Insight Pipeline ingests raw scraped Meta Threads posts (rife with slang, emojis, handles, and hashtags), runs strict PII sanitation, assigns topic classifications, and infers demographic signals (Age Group & Gender). Ambiguous posts are isolated as “Unspecified” outliers so that aggregate percentage calculations remain mathematically sound.

Key Code Locations (Reference Route)

1. User Input & Pre-Validation: src/components/InputWorkbench.tsx

Houses the textarea, live character counter, “Load Sample Scraped Data” handler, and client-side empty-input alert that catches blank submissions before network calls.

2. Server-Side Extraction & PII Scrubbing: src/app/api/extract/route.ts & src/lib/gemini.ts

Route handler invoking Google Gemini 2.5 Flash with structured output mode. Strips usernames, emails, and phone numbers from raw text, assigns topic categories, and infers age/gender signals.

3. Statistical Outlier Math: src/lib/metrics.ts

Calculates topic distribution percentages across all posts, but filters out “Unspecified” demographic posts from the base denominator—tracking them as dedicated outlier counters to keep identified percentages mathematically accurate.

4. Dashboard Visualization & Export: src/components/AnalyticsOverview.tsx & JsonOutputViewer.tsx

Renders progress bars, summary cards, and the 1-click clipboard export with visual confirmation.

To Change This, Start Here

  • Add or rename topic categories: Update CategoryEnum in src/lib/schemas.ts and update the category taxonomy prompt in src/lib/gemini.ts.
  • Add more realistic sample posts: Edit SAMPLE_THREADS_RAW_TEXT in src/data/sampleThreadsData.ts.
  • Configure live Gemini API key: Add GEMINI_API_KEY=your_key to .env.local. (The app gracefully uses its built-in engine if no key is supplied).

A Practice to Reuse

Strict Schema Contracts + Explicit Outlier Isolation

When processing uncurated real-world text with LLMs, always separate detection certainty from aggregate metrics. By explicitly enforcing an “Unspecified” state in your Zod schema and excluding those records from the base denominator in src/lib/metrics.ts, you prevent sparse or ambiguous posts from mathematically skewing your analytical findings.
